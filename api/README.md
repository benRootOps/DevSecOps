# EduShere

EduShere est une plateforme SaaS moderne de gestion universitaire.

---

## 🚀 Description

EduShere permet de gérer efficacement :

- Les étudiants
- Les inscriptions
- Les établissements
- Les comptes administrateurs
- Les processus de validation
